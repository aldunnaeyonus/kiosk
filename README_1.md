Check-in is the first physical touchpoint of your event. The **Big Dog Tags** mobile app removes queues, stress, and friction — delivering a fast entry experience for guests and a real-time dashboard for event teams.

---

## 🚀 Deployment Modes

The Big Dog Tags mobile app operates in two flexible configurations:

| Mode | How it works | Best for |
|---|---|---|
| **🔗 Integrated Mode** | Synchronizes real-time attendance, guest attributes, and engagement data directly with the Big Dog Tags **Core Event Marketing Platform**. | Enterprise event suites and multi-event programs |
| **📄 Standalone Mode (DIY)** | Instant **CSV / XLSX** guest list uploads directly to the app — no platform integration required. | One-off events, pop-ups, and rapid deployments |

---

## ⭐ Core Features

- **📱 Universal Device Compatibility** — Optimized layout and performance for both iPhone and iPad, allowing mixed-device team deployment on-site.
- **🔍 Instant Guest List Search** — High-performance, real-time search across thousands of attendees with low latency.
- **📊 Live Analytics Dashboard** — Monitor entry velocity, guest arrival percentages, and VIP status in real time.
- **🛡️ Offline Resilience** — Maintains local data persistence to guarantee continuous check-ins during network disruptions.
- **🔄 Multi-Device Sync** — Automatic cloud sync across all active staff devices at entry points.

## 🏁 Getting Started

### 1. Standalone / DIY Guest List Setup

1. Export your guest list in `.csv` or `.xlsx` format.
2. Ensure columns contain at minimum:

   | Required Column |
   |---|
   | First Name |
   | Last Name |
   | Email |
   | Ticket Type / Group |

3. Import the file via the app interface or administrative portal.
4. Distribute device setup keys to your check-in team.

### 2. Integrated Setup

1. Link the app to your **Big Dog Tags Core Event Marketing Platform** account via **QR code** or **OAuth login**.
2. Select the active event from your dashboard.
3. Live attendee records will sync automatically across all paired check-in terminals.
